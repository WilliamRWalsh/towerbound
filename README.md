# Towerbound

Towerbound is a portrait-mode mobile game project built with Godot 4.7.

## Getting started

1. Open this directory in Godot 4.7 or later.
2. Run the project. The main scene is `scenes/main.tscn`.

The project currently contains a starter screen and an iOS export preset. The `build/` directory contains generated iOS export output and is excluded from version control.
