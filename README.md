# Towerbound

Towerbound is a portrait-mode mobile game built with Godot 4.7: a fantasy card game crossed with tower defense. You draw cards, spend mana to build towers and cast spells, and defend a castle through ten waves of skeletons, goblins, zombies, and giants.

## Getting started

1. Open this directory in Godot 4.7 or later.
2. Run the project. The main scene is `scenes/main.tscn`.
3. Run the tests with `./run_tests.sh`.

`run_ios_simulator.sh` and `run_ios_device.sh` export and launch the game on an iOS simulator or a connected iPhone. The `build/` directory holds generated export output and is excluded from version control.

`CLAUDE.md` is the project brief. It covers the game design, the milestones, the code architecture, and how to add cards, enemies, towers, and effects.
